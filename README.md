# Описание:

- Создан класс продукты и класс категории с атрибутами и методами.
- Оптимизирована работа с родительскими классами путем создания абстрактных классов и классов наследников.
- Создан базовый абстрактный класс с именем BaseProduct, который станет родительским для класса продуктов.
- Реализован класс-миксин, который при создании объекта печатает в консоль информацию о том, от какого класса и с какими параметрами был создан объект.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/DmitryPikov/OOP.git
```
2. Тестирование:
```
pytest
```
3. Тесты покрывают следующие модули:
- `product`: функция `__init__`.
- `category`: функция `__init__`.

Покрытие тестами составляет более 80% кода проекта.
