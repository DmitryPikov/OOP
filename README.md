# Курсовая работа: приложение для анализа транзакций

## Описание:

Создан класс продукты и класс категории с атрибутами и методами.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/DmitryPikov/OOP.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Тестирование:
```
pytest
```
4. Тесты покрывают следующие модули:
- `product`: функция `__init__`.
- `category`: функция `__init__`.

Покрытие тестами составляет более 80% кода проекта.
